# Guia de Internacionalização (i18n) - MinerU Desktop Client

Este documento descreve o sistema de internacionalização do projeto e como adicionar suporte a novos idiomas.

## Visão Geral

O projeto usa **gettext** para internacionalização, que é o padrão Python para i18n.

### Idiomas Suportados

- **pt_BR** (Português Brasileiro) - Padrão
- **en_US** (Inglês) - Disponível
- Outros idiomas podem ser adicionados facilmente

## Estrutura de Diretórios

```
MinerU-linux-desktop/
├── locale/
│   ├── pt_BR/
│   │   └── LC_MESSAGES/
│   │       ├── mineru.po       # Traduções em português
│   │       └── mineru.mo       # Compilado (binário)
│   ├── en_US/
│   │   └── LC_MESSAGES/
│   │       ├── mineru.po       # Traduções em inglês
│   │       └── mineru.mo       # Compilado (binário)
│   └── messages.pot            # Template de tradução
├── i18n.py                     # Módulo de inicialização i18n
└── extract_messages.py         # Script para extrair strings
```

## Como Usar i18n no Código

### 1. Importar a função de tradução

```python
from i18n import _

# Em qualquer arquivo Python
text = _("Hello, World!")
```

### 2. Marcar strings para tradução

```python
# Strings simples
button_text = _("Add Files...")
label = _("Processing")

# Strings com formatação
message = _("Uploaded {count} files").format(count=5)

# Strings multilinha
help_text = _(
    "Select the output directory where "
    "processed files will be saved"
)

# Plurais
def get_message(n):
    if n == 1:
        return _("1 file selected")
    else:
        return _("{n} files selected").format(n=n)
```

### 3. Exemplo Completo

**Antes (sem i18n)**:
```python
class MainWindow(QMainWindow):
    def setup_ui(self):
        self.setWindowTitle("MinerU Desktop Client")
        self.button = QPushButton("Add Files...")
        self.label = QLabel("Select files to process")
```

**Depois (com i18n)**:
```python
from i18n import _

class MainWindow(QMainWindow):
    def setup_ui(self):
        self.setWindowTitle(_("MinerU Desktop Client"))
        self.button = QPushButton(_("Add Files..."))
        self.label = QLabel(_("Select files to process"))
```

## Workflow de Tradução

### 1. Extrair Strings do Código

```bash
# Executar script de extração
python extract_messages.py

# Isso gera/atualiza locale/messages.pot
```

### 2. Atualizar Traduções Existentes

```bash
# Para português
msgmerge --update locale/pt_BR/LC_MESSAGES/mineru.po locale/messages.pot

# Para inglês
msgmerge --update locale/en_US/LC_MESSAGES/mineru.po locale/messages.pot
```

### 3. Editar Arquivo .po

Abra `locale/pt_BR/LC_MESSAGES/mineru.po` em um editor:

```po
# Arquivo de tradução
msgid ""
msgstr ""
"Content-Type: text/plain; charset=UTF-8\n"

# String em inglês (original)
msgid "Add Files..."
# Tradução em português
msgstr "Adicionar Arquivos..."

msgid "Processing"
msgstr "Processando"

msgid "Upload completed!"
msgstr "Upload concluído!"
```

**Editores Recomendados**:
- [Poedit](https://poedit.net/) - Editor visual
- [GTranslator](https://wiki.gnome.org/Apps/Gtranslator) - GNOME
- Qualquer editor de texto

### 4. Compilar Traduções

```bash
# Compilar português
msgfmt locale/pt_BR/LC_MESSAGES/mineru.po -o locale/pt_BR/LC_MESSAGES/mineru.mo

# Compilar inglês
msgfmt locale/en_US/LC_MESSAGES/mineru.mo -o locale/en_US/LC_MESSAGES/mineru.mo

# Ou usar script helper
python compile_translations.py
```

### 5. Testar Traduções

```bash
# Testar em português (padrão)
python main.py

# Testar em inglês
LANGUAGE=en_US python main.py

# Ou
export LANGUAGE=en_US
python main.py
```

## Adicionar Novo Idioma

### 1. Criar Estrutura de Diretórios

```bash
# Para espanhol (es_ES)
mkdir -p locale/es_ES/LC_MESSAGES
```

### 2. Inicializar Arquivo de Tradução

```bash
# Copiar template
msginit --input=locale/messages.pot \
        --locale=es_ES \
        --output=locale/es_ES/LC_MESSAGES/mineru.po
```

### 3. Traduzir Strings

Edite `locale/es_ES/LC_MESSAGES/mineru.po`:

```po
msgid "Add Files..."
msgstr "Agregar Archivos..."

msgid "Processing"
msgstr "Procesando"
```

### 4. Compilar

```bash
msgfmt locale/es_ES/LC_MESSAGES/mineru.po \
       -o locale/es_ES/LC_MESSAGES/mineru.mo
```

### 5. Testar

```bash
LANGUAGE=es_ES python main.py
```

## Módulo i18n.py

Conteúdo de `i18n.py`:

```python
"""Internationalization module.

This module configures gettext for the application.
Usage:
    from i18n import _
    text = _("Hello")
"""

import gettext
import locale
import os

# Diretório de traduções
LOCALE_DIR = os.path.join(os.path.dirname(__file__), 'locale')

# Detectar idioma do sistema
try:
    # Tentar detectar idioma do sistema
    system_locale, encoding = locale.getdefaultlocale()
    if system_locale:
        language = system_locale
    else:
        language = 'pt_BR'  # Padrão
except Exception:
    language = 'pt_BR'

# Permitir override via variável de ambiente
language = os.environ.get('LANGUAGE', language)

# Configurar gettext
try:
    translator = gettext.translation(
        'mineru',
        localedir=LOCALE_DIR,
        languages=[language],
        fallback=True
    )
    _ = translator.gettext
except Exception as e:
    # Fallback: retornar string original
    def _(message):
        return message

# Expor função de tradução
__all__ = ['_']
```

## Script extract_messages.py

```python
"""Extract translatable strings from source code.

This script scans all Python files and extracts strings marked
for translation using the _() function.
"""

import os
import subprocess

# Arquivos para escanear
SOURCE_FILES = [
    'main.py',
    'mineru_client.py',
    'settings_dialog.py',
    'i18n.py'
]

# Arquivo de saída
OUTPUT_FILE = 'locale/messages.pot'

# Informações do projeto
PROJECT_NAME = 'MinerU Desktop Client'
VERSION = '1.0.1'

def extract_messages():
    """Extract messages from source files."""
    # Criar diretório locale se não existir
    os.makedirs('locale', exist_ok=True)

    # Comando xgettext
    cmd = [
        'xgettext',
        '--language=Python',
        '--keyword=_',
        '--output=' + OUTPUT_FILE,
        '--from-code=UTF-8',
        f'--package-name={PROJECT_NAME}',
        f'--package-version={VERSION}',
        '--msgid-bugs-address=your@email.com',
    ] + SOURCE_FILES

    try:
        subprocess.run(cmd, check=True)
        print(f"Messages extracted to {OUTPUT_FILE}")
    except subprocess.CalledProcessError as e:
        print(f"Error extracting messages: {e}")
    except FileNotFoundError:
        print("xgettext not found. Install gettext tools:")
        print("  Ubuntu/Debian: sudo apt install gettext")

if __name__ == '__main__':
    extract_messages()
```

## Script compile_translations.py

```python
"""Compile translation files (.po → .mo).

This script compiles all .po files to .mo binary format.
"""

import os
import subprocess
from pathlib import Path

def compile_translations():
    """Compile all .po files to .mo."""
    locale_dir = Path('locale')

    # Encontrar todos os arquivos .po
    po_files = locale_dir.glob('*/LC_MESSAGES/*.po')

    for po_file in po_files:
        mo_file = po_file.with_suffix('.mo')

        print(f"Compiling {po_file} → {mo_file}")

        try:
            subprocess.run(
                ['msgfmt', str(po_file), '-o', str(mo_file)],
                check=True
            )
        except subprocess.CalledProcessError as e:
            print(f"Error compiling {po_file}: {e}")
        except FileNotFoundError:
            print("msgfmt not found. Install gettext tools:")
            print("  Ubuntu/Debian: sudo apt install gettext")
            return

    print("All translations compiled successfully!")

if __name__ == '__main__':
    compile_translations()
```

## Boas Práticas

### 1. Strings Completas

```python
# ✅ Bom
message = _("Upload completed successfully!")

# ❌ Ruim (dificulta tradução)
message = _("Upload") + " " + _("completed") + " " + _("successfully!")
```

### 2. Context para Strings Ambíguas

```python
# Usar comentários para dar contexto
# Translators: Button label for opening output folder
open_button = _("Open")

# Translators: Menu item for opening settings
settings_menu = _("Open")
```

### 3. Formatação de Strings

```python
# ✅ Bom (tradutores podem reordenar)
message = _("User {name} uploaded {count} files").format(
    name=username,
    count=file_count
)

# ❌ Ruim (ordem fixa)
message = _("User %s uploaded %d files") % (username, file_count)
```

### 4. Plurais

```python
from i18n import _, ngettext

# Para idiomas com regras de plural complexas
def get_file_message(n):
    return ngettext(
        "{n} file selected",
        "{n} files selected",
        n
    ).format(n=n)
```

### 5. Não Traduzir

```python
# Não traduzir:
# - URLs
# - Nomes de arquivos/paths
# - Chaves de API
# - Formatos técnicos

# ✅ Bom
url = "https://mineru.net/api/v4"
api_key = config.get("api_key")
filename = "output.pdf"

# ❌ Ruim
url = _("https://mineru.net/api/v4")  # Não faz sentido
```

## Resolução de Problemas

### Traduções Não Aparecem

1. Verificar que arquivo .mo foi compilado:
   ```bash
   ls -la locale/pt_BR/LC_MESSAGES/mineru.mo
   ```

2. Verificar variável LANGUAGE:
   ```bash
   echo $LANGUAGE
   ```

3. Limpar cache Python:
   ```bash
   find . -type d -name __pycache__ -exec rm -rf {} +
   ```

### Encoding Issues

Sempre use UTF-8:

```python
# No arquivo .po
"Content-Type: text/plain; charset=UTF-8\n"
```

### Strings Não Extraídas

Verificar que usa o padrão correto:

```python
# ✅ Será extraído
text = _("Message")

# ❌ Não será extraído
def get_text():
    return gettext("Message")
```
